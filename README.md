# Мод карты для FreakRating

Список «Кто где» сверху, объёмная карта снизу, с зазором от хотбара.

## Установка

1. Установи чистый лаунчер: https://github.com/dhshfhd2-bot/FreakRating-Launcher
2. Скопируй файл `mods/map.js` в папку `mods` рядом с `FreakRating.exe`.
3. Перезапусти лаунчер. При первом запуске страница перезагрузится один раз — это нормально, применяется настройка раскладки.

Ссылка на оригинальный лаунчер: https://github.com/Egorrko/freakrating-client
