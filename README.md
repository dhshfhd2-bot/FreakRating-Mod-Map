# Мод: карта

Что делает: список «Кто где» сверху, объёмная карта снизу с зазором от хотбара.

## Как поставить

1. Скачай файл `mods/map.js`.
2. Положи его в папку `mods` рядом со `start.bat`:
   ```
   FreakRating-Client-Mods\mods\map.js
   ```
3. Перезапусти `start.bat`. При первом запуске страница перезагрузится один раз — это применяется раскладка.

Чтобы удалить — удали `map.js` из папки `mods`.
